# Mohammed Nasib K N — Portfolio

A framework-free static portfolio for Mohammed Nasib K N. The site uses plain HTML, CSS, and JavaScript, and is served directly from the repository root.

## Local preview

Open `index.html` in a browser. No package installation or build step is required.

## Deploy to Vercel

Import this repository into Vercel and keep the project rooted at the repository root. This is a static site: leave the framework preset as **Other**, leave the build command empty, and use `.` as the output directory. Vercel serves `index.html` and the local assets directly.

## Before publishing

Verify these items before making the portfolio public:

- Confirm the contact details and public profile URLs remain correct: email, Qatar phone, GitHub, and LinkedIn.
- Recheck employer, project attribution, role dates, and technical descriptions for accuracy, including the previous DCF work.
- Confirm that the portrait is approved for publication.
- Keep Frappe / ERPNext framed as an emerging career direction: familiarity with DocTypes and workflows is not represented as professional implementation experience.

The portfolio lists Doha, Qatar as the current location. Contact links are actionable and use `mailto:` and `tel:` for email and phone.
